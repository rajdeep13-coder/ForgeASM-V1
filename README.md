# DEVWRAP Project Skeleton

Boiler template for the DevWrap event.

## Project Structure

Use this structure as the default base for your build:

```text
public/
	assets/
		images/          # png or jpg files (if used)

src/
	css/               # styling
	js/                # logic
	components/        # reusable components
```

## Instructions

1. Maintain a clean and organized structure.
2. Use AI responsibly.
3. Build interactive features.
4. Build your project inside this structure.
5. You can modify or extend the structure freely if your idea needs it.

## Quick Start

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Create production build:

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```
